# Crisp Home Assignment

Deployed at: https://crisp.chrispaganon.com

## Some adjustments I made

1. Used Lucide icon instead of the icons in Figma. In a real case scenario I assume I'd have access to the same icon library as you instead.
2. I made significant changes to the comparison table on mobile and tablet. The desktop version left the Crisp column in hidden overflow on the far right side. Users had to scroll horizontally to see Crisp.
3. I didn't match figma dimensions pixel-to-pixel so far. If the current design isn't close enough I'll happilly give it another pass to match it more closely.

## Setup

Install dependencies and start Nuxt:

```bash
pnpm install
pnpm dev
```
